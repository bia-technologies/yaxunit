# Синтаксические грабли BSL

Только правила, которые не выводятся из общих знаний о 1С:

- **В общем модуле (CommonModule) нельзя объявлять переменные уровня модуля** — платформа не откомпилирует такой модуль. Ловушка при переносе кода из модуля формы/объекта в общий: состояние переноси в параметры или сеансовые данные.

- **Массив со значениями в этом репозитории** — через метод фреймворка:
  ```bsl
  Массив = ЮТКоллекции.ЗначениеВМассиве("a", "b", "c");
  ```
  (а не поштучный `Добавить()` и не `Новый Массив("a", "b", "c")` — конструктор параметров не принимает).
