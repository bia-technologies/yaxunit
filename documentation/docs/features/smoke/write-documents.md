# Тестирование проведения документов

## Возможности

Дымовые тесты проведения документов позволяют проверить, что документы перепроводятся, не выбрасывая исключений. Для теста берется последний проведенный документ из базы по упорядочиванию: `УПОРЯДОЧИТЬ ПО Документы.Дата УБЫВ`.

Если подходящий документ не найден, тест помечается как пропущенный.

:::caution
Документы перепроводятся в том же сеансе. Менеджер и клиент тестирования не используется.
:::

### Виды тестов

Реализован один вид теста проведения документов:

* `Проведение` - перепроводит последний существующий проведенный документ

### Учет прав

При формировании списка тестов учитываются права доступа текущего пользователя, что позволит выполнить тестирование для разных ролевых моделей. При добавлении теста проверяется наличие права `Проведение` на объект метаданных.

Документы, у которых в метаданных запрещено проведение, в список тестов не добавляются.

### Фильтрация

Настройки для фильтрации/исключения тестов:

* Фильтр по объектам метаданных с возможностью использовать шаблоны со звездочкой (например, `Удалить_*`)


### Перехват исключений

При запуске на 1С:Предприятие версии 8.3.17.1091 или больше будет выполняться автоматический перехват и обработка исключения используя [механизм отображения ошибок](https://wonderland.v8.1c.ru/blog/razvitie-mekhanizma-otobrazheniya-oshibok/).

## Настройки

Настройки имеют древовидную структуру:

```plain
└─ ДымовыеТесты                                                     // Уровень 0
   └─ ПроведениеДокументов                                          // Уровень 1
      └─ [Исключения] имя объекта метаданных                        // Уровень 2

```

Базовая настройка для теста проведения документов:

```json
{
    "ДымовыеТесты": {
        "Использовать": true,
        "ПроведениеДокументов": {
            "Использовать": true,
            "Исключения": [
                "Удалить*"
            ]
        }
    }
}
```


### Настройка тестов проведения документов

| Имя параметра            | Тип               | Значение по умолчанию | Описание                                                                                           |
|--------------------------|-------------------|-----------------------|----------------------------------------------------------------------------------------------------|
| `Использовать`           | `boolean`         | `false`               | Использование тестов проведения документов                                                         |
| `Исключения`             | `Array\|String`   | `Null`                | Имена исключаемых объектов, возможно использование шаблонов со звездочкой                          |
