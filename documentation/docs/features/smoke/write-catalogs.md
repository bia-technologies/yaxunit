# Тестирование записи справочников

## Возможности

Дымовые тесты записи справочников, позволяют проверить, что элементы справочников и группы иерархических справочников записываются, не выбрасывая исключений. Для теста берется 1 случайный элемент из базы по упорядочиванию: `УПОРЯДОЧИТЬ ПО ОбъектМетаданных.Ссылка УБЫВ`

:::caution
Формы открываются в том же сеансе. Менеджер и клиент тестирования не используется.
:::

### Виды тестов

Реализовано 2 вида тестов записи справочников:

* `Элементы` - Записывает элемент справочника
* `Группы` - Записывает группу справочника


### Учет прав

При формировании списка тестов учитываются права доступа текущего пользователя, что позволит выполнить тестирование для разных ролевых моделей. При добавлении теста проверяется наличие права `Изменение` на объет метаданных.


### Фильтрация

Настройки для фильтрации/исключения тестов:

* Фильтр по видам тестов (Элементы/Группы). Глубой настройки на уровне элементов и групп нет. Их можно только включить или выключить
* Фильтр по объектам метаданных с возможностью использовать шаблоны со звездочкой (например, `Удалить_*`)


### Перехват исключений

При запуске на 1С:Предприятие версии 8.3.17.1091 или больше будет выполняться автоматический перехват и обработка исключения используя [механизм отображения ошибок](https://wonderland.v8.1c.ru/blog/razvitie-mekhanizma-otobrazheniya-oshibok/).

## Настройки

Настройки имеют древовидную структуру:

```plain
└─ ДымовыеТесты                                                     // Уровень 0
   └─ ЗаписьСправочников                                            // Уровень 1
      └─ [Вид теста] Элементы, Группы                               // Уровень 2
      └─ [Исключения] имя объекта метаданных                        // Уровень 2

```

Базовая настройка для теста записи справочников:

```json
{
    "ДымовыеТесты": {
        "Использовать": true,
        "ЗаписьСправочников": {
            "Использовать": true,
            "Элементы": true,
            "Группы": true,
            "Исключения": [
                "ИдентификаторыОбъектовМетаданных",
                "ИдентификаторыОбъектовРасширений",
                "ПредопределенныеВариантыОтчетов",
                "удалить*",
                "Удалить*"
            ]
        }
    }
}
```

Глубой настройки на уровне элементов и групп нет - нельзя задать какие объекты метаданных нужно исключить из записи элементов, а какие из записи групп. Только общая настройка на уровней исключений. Элементы или группы можно только включить или выключить.


### Настройка тестов открытия форм

| Имя параметра            | Тип               | Значение по умолчанию | Описание                                                                                           |
|--------------------------|-------------------|-----------------------|----------------------------------------------------------------------------------------------------|
| `Использовать`           | `boolean`         | `true`                | Использование тестов записи справочников                                                           |
| `Элементы`               | `boolean`         | `true`                | Использование тестов записи элементов справочников.                                                |
| `Группы`                 | `boolean`         | `true`                | Использование тестов записи групп справочников.                                                    |
| `Исключения`             | `Array\|String`   | `Null`                | Имена исключаемых объектов, возможно использование шаблонов со звездочкой                          |
